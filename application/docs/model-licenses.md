# Model licenses in exported models

When a model is downloaded in a deployable format (OpenVINO IR or ONNX), the archive includes a `README.md` with a
"Licensing" section that references the model license, by name and URL, as declared in the model manifest
(`license.name` and `license.url`). For licenses whose terms require it, the archive also includes a copy of the
license text and any other required notice.

The mapping between licenses and bundled files is defined in `_LICENSE_FILES_BY_NAME` in
`application/backend/app/services/demo_files_service.py`. The license texts are stored in
`application/backend/app/supported_models/licenses/`.

## Adding a model with a new license

The unit test `tests/unit/services/test_demo_files_service.py::TestLicenseFiles::test_all_used_licenses_are_handled`
fails when a model manifest or the timm catalog uses a license that has no redistribution policy. In that case:

1. Check whether the license terms require a copy of the license (or other notices) to be redistributed together
   with the model weights.
2. If so, add the license text under `application/backend/app/supported_models/licenses/` and a corresponding entry
   in `_LICENSE_FILES_BY_NAME`.
3. Otherwise, add the license name to `_LINK_ONLY_LICENSES` in the test.
